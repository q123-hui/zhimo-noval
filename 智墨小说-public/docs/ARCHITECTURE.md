# 架构说明

## 1. 端侧结构

```
┌───────────────────────────────────────────────┐
│  同一套前端代码（HTML / CSS / JS）             │
│  web/  ──► 浏览器                              │
│  mobile/ ──► Android（WebView 容器内加载）     │
│  electron/ ──► macOS 桌面（本地 http server）  │
└───────────────────────────────────────────────┘
              │  fetch /api/ai（SSE 流式）
              ▼
┌───────────────────────────────────────────────┐
│  转发层（Cloudflare Pages Function / Worker）  │
│  · 注入服务端 API Key（客户端零密钥）          │
│  · 校验激活码 → 设备绑定 → 扣减额度            │
│  · 统一超时、重试、错误码                      │
└───────────────────────────────────────────────┘
              │  Authorization: Bearer ***（服务端持有）
              ▼
        大模型 API（OpenAI 兼容）
```

## 2. 请求链路（一次章节生成）

1. 组装上下文：`世界观 + 人物卡 + 最近正文 + 本章要点`
2. 本地估算 token，超出预算时按优先级裁剪
3. POST 转发层，`stream: true`
4. 逐块解析 `data:` 行，取 `choices[0].delta.content` 增量渲染
5. 收到 `[DONE]` 结束；`finish_reason=length` 时提示"继续"并从中断处续写
6. 结果落本地存储，同时更新章节摘要（供下次上下文使用）

## 3. 上下文管理策略

| 层 | 内容 | 保留策略 |
|---|---|---|
| 常驻 | 世界观、人物卡、写作风格 | 永不裁剪 |
| 近期 | 最近 1–2 章正文 | 优先保留，超预算时截断尾部 |
| 摘要 | 更早章节的情节摘要 | 按需压缩，冲突时重生成 |
| 丢弃 | 闲聊、被否掉的草稿 | 直接移除 |

## 4. 在线更新

```
App 启动 ──GET update.json──► { versionCode, versionName, md5, url, notes }
      │
      ├─ md5 相同 → 跳过
      └─ md5 不同 → 下载 APK → 校验 md5 → 拉起系统安装器
```

不依赖应用商店审核，改完代码打包即上线；下载失败/被拦截时给出网络与权限层面的诊断提示。

## 5. 授权与设备绑定

- 激活码在服务端 KV 中记录：状态、有效期、额度、已绑定设备列表
- 客户端上报设备标识，超过上限拒绝激活
- 转发层按次扣减额度，返回剩余额度 / 剩余天数的响应头供前端展示

## 6. 为什么密钥不放客户端

移动端 APK 可被反编译，任何写进包里的字符串都视为公开。因此安装包内只保留一个转发地址，密钥与模型选择全部在服务端，换模型、限流、灰度都无需重新发版。
